# 오늘의 개념
## Python의 변수란?
C의 변수와 비교해보는 것도 좋겠다. 우선, C의 변수는 사실 정말 진정한 의미에서, 변수라고도 할 수 있다. \
왜? 그럼 memory에 실제로 그 변수가 "쓰이기" 때문이다.  \
어셈블리 적으로 생각하면 registry에 그 변수를 할당하고, save 계열의 명령어를 부르면 실제로 그 메모리의 값이 overwrite된다는 것은 알고 있을 것이다. \
Python에서는 좀 다르게 일단 거의 대부분의 무언가는 "객체", 흔히 말하는 object화 되어 있다. \
변수는 그 객체에 붙은 alias로 보는 것이 더 타당하다. 
```python
a = [1, 2]
```
이와 같은 작업은 리스트 객체를 만들고 a라는 이름을 붙이는 것이고, 
```python
b = a
```
이것 또한 새 객체를 생성하는 것이 아니라 alias를 하나 더 생성하는 것이다. \
모든 객체는 `id`를 가지며, `is`는 같은 객체인지(is same id?), `==`는 같은 값인지(is same value?)를 연산한다. \
객체는 크게 불변타입과 가변타입으로 나눠지고, 불변 타입에 대입 연산을 할때는 실제로는 새 객체를 생성하고 대체하는 작업이 진행된다. 

불변 객체는, `int`, `str`, `tuple`, `frozenset`등이 있고, \
가변 객체는, `list`, `dict`, `set`등이 있다.
